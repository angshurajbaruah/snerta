## Participant data

Session exports in `docs/sessions/` were contributed by people who looked at their own file
first and agreed to it being published. They contain no name, account, location or device
identifier — only timings, tap coordinates, viewport size and self-reported comfort labels.

If you contribute a session and later want it removed, open an issue and it will be deleted.
No explanation needed.

Files in `docs/synthetic/` were generated by code. Nobody produced them, they are not data,
and that folder's README says so at more length.
