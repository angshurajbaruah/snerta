# Archived K’ab identity

The product was named **K’ab** until 2026-11-13, when it was renamed **snerta** with a new
Brand Identity 2.0. These are the original user-approved K’ab assets and the script that
prepared the fingerprint mark for the web. Nothing here is used by the application any more.

Kept because they are user-provided source material and part of the project's history, not
because they are current. The current identity is the wordmark `snerta.` in Montserrat; see
`docs/DECISION_LOG.md` and the design canvas linked in `README.md`.
