# Synthetic sessions — not evidence

Every file in this folder was generated by code. **No person produced any of it.**

They exist for one reason: to exercise code paths that no real session covers. All four
real pilot sessions ran on a 393×695 screen. Nothing has ever run at **430×932** (a Pro Max),
and the **left-handed rail** has one real session behind it. A layout bug could be sitting
in either and the pilot would never find it.

## What they are not

They are not findings, not participants, not a sample, and not something to chart. The
numbers inside were written to be *plausible*, which is exactly what makes them dangerous:
they look like data and contain no information. They were shaped from the published reach
literature in `../EVIDENCE_BASE.md`, not from anybody's thumb.

Three guards, because labelling alone is not enough:

1. Each file carries a `SYNTHETIC` banner as its first key and `"synthetic": true`.
2. Every filename begins with `SYNTHETIC-`.
3. `scripts/analyse-sessions.cjs` **refuses to run at all** on a folder containing one, and
   says why. It is a hard stop rather than a quiet filter, because a filter can be removed
   by accident and a refusal cannot.

## Regenerating

```
node scripts/make-synthetic.cjs
```

Deterministic from a fixed seed, so the files are reproducible and obviously manufactured.
